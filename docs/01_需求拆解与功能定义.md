# NetEye 需求拆解与功能定义 v1.0

> 目标：做一个 Wireshark 级别的网络端口监控/抓包分析工具，覆盖其核心能力 80% 以上，并内置 AI 对话分析（含语音输入）。

---

## 1. 需求拆解

原始需求拆为 6 个能力域，逐条对应交付物：

| 域 | 用户原话 | 拆解后的具体能力 | 对应 Wireshark 模块 |
|---|---|---|---|
| A 捕获 | 监控网络端口/参考 Wireshark | 网卡选择、混杂模式、BPF 捕获过滤、快照长度、启停/暂停、环形缓冲、多文件 | Capture / Capture Options |
| B 原始数据 | 有原始数据 | 十六进制 + ASCII 双栏视图、原始字节导出、pcap 落盘 | Packet Bytes |
| C 解析数据 | 解析数据 | 分层协议树（Frame→Eth→IP→TCP→应用）、逐字段偏移标注 | Packet Details |
| D 曲线 | 曲线 | 实时 bps/pps 曲线、多序列 IO Graph（按过滤器分线）、RTT 分布 | I/O Graph / Statistics |
| E 端口状态 | 端口状态 | ①本机监听端口表（TCP/UDP + 进程 + 状态）②抓包层端口流量 TopN / 会话矩阵 | 无直接对应（增强项） |
| F 存储 | 可以保存数据 | SQLite 索引 + pcap 原始文件、会话存档、导出 CSV/JSON/PCAP | Save / Export |
| G 分析统计 | 一定的分析和统计 | 协议分级、端点、会话、专家信息、TCP 流重组、异常检测 | Protocol Hierarchy / Conversations / Expert Info |
| H AI | 嵌入 AI，对话查询分析 | 对话窗 + Function Calling 工具集 + 语音输入 | 无（增强项） |

## 2. 环境勘察结果（本机实测）

| 项目 | 结果 | 影响 |
|---|---|---|
| Npcap / WinPcap | **未安装**（无 wpcap.dll） | Windows 下抓包必需，需用户安装（免费，需管理员） |
| Wireshark / tshark | 未安装 | 不考虑 tshark 后端，纯自研解析 |
| Python | 3.14.3 / 3.13.12（64-bit） | 版本很新，需避开无 wheel 的库 |
| Node | v22.22.2 / npm 10.9.7 | 前端构建 OK |
| scapy | 2.7.0 纯 Python wheel **可装** | 定为主解析/捕获引擎 |
| pypcap | 编译失败，**排除** | 改用 scapy 自带 Npcap 通道 |
| 网卡 | 以太网（未连接）、WLAN（已连接） | 可抓 |
| AI API Key | 环境内未发现 | 需在软件内配置或用户提供 |

## 3. 关键约束与风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 抓包权限 | 必须管理员运行 + Npcap | 主引擎 Npcap；**降级引擎**：raw socket + SIO_RCVALL（仅需管理员，抓 IPv4，无以太网头），保证无 Npcap 也能跑 |
| Python 3.14 兼容性 | 部分库无 wheel | 已实测 scapy OK；其余一律用纯 Python/主流库（FastAPI、uvicorn、websockets 需实测） |
| 性能 | UI 显示万级包会卡 | 前端虚拟滚动 + 后端分页 + 环形内存缓冲（默认 100k 包） |
| AI 幻觉 | AI 编造不存在的包 | 强制走 Function Calling，AI 只能调用工具取数，答案必须带包序号引用 |
| 语音 | 浏览器方案依赖 Chrome/Edge | 主用 Web Speech API（中文），可选本地 faster-whisper 兜底 |

## 4. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 捕获引擎 | scapy（Npcap 通道）/ raw socket 降级 | 纯 Python wheel 可用，解析层自带 300+ 协议 |
| 后端 | FastAPI + uvicorn + WebSocket | 与用户既有 TestCopilot 技术栈一致；WebSocket 推送实时包 |
| 前端 | React + Vite + TypeScript | 曲线/表格/AI 窗最好做 |
| 图表 | ECharts | 大数据量曲线性能好 |
| 存储 | SQLite（包索引+统计） + 本地 pcap 文件 | 轻量、可查询、可导出 |
| AI | OpenAI Chat Completions 兼容协议（DeepSeek / OpenAI / 通义 / Ollama 可切换） | 一套代码适配所有，支持 function calling |
| 语音输入 | Web Speech API（webkitSpeechRecognition，zh-CN） | 零安装，Edge/Chrome 直接可用 |

## 5. 功能定义（对照 Wireshark 覆盖率）

### 5.1 捕获（A）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| A1 | 网卡枚举与选择 | 列出所有网卡（含 IP、MAC、描述） | P0 |
| A2 | 开始/暂停/停止/重启捕获 | | P0 |
| A3 | 混杂模式开关 | | P0 |
| A4 | BPF 捕获过滤器 | `tcp port 80`、`host 192.168.1.1` | P0 |
| A5 | 快照长度（snaplen） | 默认 65535 | P1 |
| A6 | 环形缓冲 / 最大包数限制 | 防内存爆 | P1 |
| A7 | 自动分片保存 | 按时长/大小滚动 | P2 |
| A8 | 多网卡同时捕获 | | P2 |

### 5.2 解析（B/C）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| B1 | 包列表 | 序号/时间/源/目的/协议/长度/Info，虚拟滚动 | P0 |
| B2 | 协议树详情 | 分层展开，字段名+值+字节偏移 | P0 |
| B3 | 十六进制视图 | 16 字节/行 + ASCII，点击联动高亮字段 | P0 |
| B4 | 基础协议 | Eth / VLAN / ARP / IPv4 / IPv6 / ICMP / ICMPv6 / TCP / UDP | P0 |
| B5 | 传输+应用层 | DNS / mDNS / HTTP / TLS(握手元数据) / DHCP / NTP / SSDP | P1 |
| B6 | 汽车电子扩展 | DoIP(ISO 13400) / SOME-IP / UDS-over-IP / XCP-ish | P1（差异化亮点） |
| B7 | TCP 选项解析 | MSS/WS/SACK/TS | P1 |
| B8 | 显示过滤器 | 自研类 Wireshark 语法：`tcp.flags.reset==1 && ip.addr==x` | P1 |
| B9 | 着色规则 | 按协议/异常着色，可自定义 | P2 |
| B10 | Follow Stream | TCP/UDP 流重组，ASCII/HEX 显示 | P1 |

### 5.3 曲线与可视化（D）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| D1 | 实时吞吐曲线 | bps / pps 双轴 | P0 |
| D2 | IO Graph | 支持多条 series，每条绑定显示过滤器 + 颜色 | P1 |
| D3 | 协议分布饼图 | | P1 |
| D4 | Top 会话/端点柱状图 | | P1 |
| D5 | RTT 分布图 | | P2 |
| D6 | 端口流量热力图 | 端口 × 时间 | P2 |

### 5.4 端口状态（E）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| E1 | 本机监听端口表 | 协议/本地地址:端口/远端/状态/PID/进程名，实时刷新 | P0 |
| E2 | 端口流量统计 | 按端口聚合包数、字节、会话数、错误数 | P0 |
| E3 | 端口异常标记 | SYN 无响应、RST 风暴、半开连接、扫描行为 | P1 |
| E4 | 端口连接时序 | 单端口的连接生命周期时间线 | P2 |

### 5.5 存储（F）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F1 | 保存为 pcap | 全部/选中/过滤后 | P0 |
| F2 | 打开 pcap 离线分析 | | P1 |
| F3 | 会话存档（SQLite） | 历史会话列表、命名、备注、加载 | P1 |
| F4 | 导出 CSV / JSON | 包列表与统计表 | P1 |
| F5 | 配置持久化 | AI 配置、过滤器预设、着色规则 | P1 |

### 5.6 分析统计（G）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| G1 | 协议分级统计 | 树形：包数/字节/占比/速率 | P0 |
| G2 | 会话统计（Conversations） | Eth/IP/TCP/UDP 四视图，按字段排序 | P0 |
| G3 | 端点统计（Endpoints） | 地址/包数/字节/首末时间 | P0 |
| G4 | 专家信息（Expert Info） | 重传/乱序/零窗口/DupACK/RST/TTL异常/DNS失败/HTTP错误 | P1 |
| G5 | 概览摘要 | 捕获时长、包数、平均速率、峰值、异常计数 | P0 |
| G6 | 异常检测规则 | 可配置阈值（重传率、RST 率、突发流量） | P2 |
| G7 | 定时快照对比 | 两次捕获差异对比 | P3 |

### 5.7 AI（H）

| # | 功能 | 说明 | 优先级 |
|---|---|---|---|
| H1 | 对话窗 | 侧边栏，流式输出，Markdown 渲染 | P0 |
| H2 | Function Calling 工具集 | 见下表，AI 只能经工具取数 | P0 |
| H3 | 语音输入 | 麦克风按钮 → Web Speech API → 文本填入输入框 | P1 |
| H4 | 上下文携带 | 自动附带当前捕获摘要与选中包 | P1 |
| H5 | 分析建议卡 | AI 返回的结论可一键跳到对应包/图表 | P2 |
| H6 | 多轮/历史 | 会话历史保存 | P2 |

**AI 可用工具（Function Calling 清单）**

| 工具 | 参数 | 作用 |
|---|---|---|
| `query_packets` | filter, limit, time_range, fields | 按显示过滤器查包 |
| `get_statistics` | type(protocol/conversation/endpoint/port) | 取统计表 |
| `get_expert_info` | severity | 取异常列表 |
| `get_io_series` | filter, bucket | 取时间序列（供 AI 判断趋势） |
| `analyze_port` | port | 单端口深度画像 |
| `get_packet_detail` | id | 单包全字段 |
| `detect_anomaly` | — | 跑规则引擎返回异常摘要 |
| `export_result` | format, scope | 导出当前结果 |

## 6. 架构

```
NetEye/
├─ docs/                    需求/设计文档
├─ server/                  Python 后端
│  ├─ app/
│  │  ├─ main.py            FastAPI 入口
│  │  ├─ capture/           engine.py(Npcap/scapy) fallback_raw.py(SIO_RCVALL)
│  │  ├─ parser/            dissect.py 协议树构建 / automotive.py(DoIP, SOME/IP)
│  │  ├─ filters/           display_filter.py  自研显示过滤引擎
│  │  ├─ stats/             aggregator.py / expert.py / io_graph.py / portstate.py
│  │  ├─ storage/           sqlite.py / pcapio.py
│  │  ├─ ai/                client.py(OpenAI兼容) tools.py(schema+执行) prompts.py
│  │  └─ api/               capture.py packets.py stats.py ai.py config.py
│  └─ requirements.txt
├─ web/                     React + Vite + TS 前端
│  └─ src/
│     ├─ pages/             Capture / Analysis / Ports / AI
│     ├─ components/        PacketList PacketDetail HexView IOChart StatsPanel AIChat VoiceButton
│     └─ store/             zustand
└─ data/                    captures/*.pcap, neteye.db
```

数据流：
```
网卡 → 捕获线程 → 解析为 PacketRecord → 环形内存缓冲
                     ├→ SQLite 索引（异步批量写）
                     ├→ 统计聚合器（协议/会话/端点/端口/IO 分桶）
                     ├→ pcap 写入（可选）
                     └→ WebSocket → 前端（增量包 + 1s 心跳统计）
```

## 9. 验收对照（v0.1.3 复核，2026-09-19）

逐条核对最初提出的 6 项原始需求：

| 原始需求 | 实现情况 | 落点 |
|---|---|---|
| 参考 Wireshark，监控网络端口 | 已实现 | 双引擎抓包（Npcap + raw socket 降级）、BPF 过滤、混杂模式、暂停/继续 |
| **原始数据** | 已实现 | 十六进制 + ASCII 视图，**字节级**与协议树字段双向联动（点字段高亮字节 / 点字节反查字段） |

| **曲线** | 已实现 | 实时吞吐曲线（包数/比特率双轴，100ms–10s 桶），可叠加过滤后曲线 |
| **端口状态** | 已实现 | 本机监听/连接表（PID+进程）、抓包层端口流量画像、异常标记 |
| **保存数据** | 已实现 | pcap 保存（全部/过滤后/选中）、会话 SQLite 存档、CSV/JSON 导出 |

| **嵌入 AI、接入 AI API、对话查询分析** | 已实现（本轮补强可见性） | DeepSeek/OpenAI 兼容/Ollama 可配；10 个 Function Calling 只读工具；流式对话 + 工具调用可视化；未配 Key 走本地规则引擎；首屏数据快照 + 一键分析；语音输入 |
| UI 简洁 | 已实现 | 单页三区布局（列表 / 详情 / 侧栏），侧栏标签带数据角标 |
